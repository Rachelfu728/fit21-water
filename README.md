# Fit21 水水小助理 💧

> **「每天兩次，剛剛好的提醒。」**  
> *不是一直催你喝水，而是在需要的時候，溫柔提醒你。*

---

## 🌟 產品定位與特色

1. **專注於單純陪伴**：不做卡路里、運動、飲食或體重趨勢等複雜功能，專注於「幫助使用者記得喝水」。
2. **適合 40～70 歲長輩與全年齡層**：
   - 特大字體與高對比色彩（Fit21 深綠 `#0F6E56` 配奶油米白 `#FBF6EC`）。
   - 超大點擊按鈕（＋200、＋300、＋500 mL），單手輕鬆按壓。
   - 零學習門檻，隨開即用。
3. **重要「不打擾邏輯」**：
   - 每天原則上只提醒兩次（預設 11:30、17:00）。
   - 當天達標後，**立即停止當天所有提醒**，不再打擾。
   - 第二次提醒後（傍晚至夜間），不再發送任何催促通知。
   - 晚上未達標不催逼：「今天沒有完成也沒關係，不需要為了達標一次喝大量的水。明天我們早一點開始 💧」。
4. **完全視覺角色融入**：
   - 使用可愛且富有質感的「Fit21 水滴小助理」角色作為 App Icon、引導主視覺、提醒頭像與達標慶祝。
5. **完整 PWA 支援**：
   - 支援離線快取（離線狀態下亦可記錄喝水與檢視歷史）。
   - 支援 iPhone Safari「加入主畫面」與 Android Chrome 一鍵安裝為手機桌面 App。

## 🚀 如何快速開啟與體驗？

專案目錄位於：  
`C:\Users\user\.gemini\antigravity\scratch\fit21-water-assistant`

### 方法一：一鍵啟動（推薦）
直接在資料夾中雙擊：  
👉 **`啟動Fit21水水小助理.bat`**  
系統會自動開啟本機專屬伺服器，並直接在您的預設瀏覽器中開啟 App。

### 方法二：直接雙擊網頁
直接雙擊開啟 **`index.html`** 即可在瀏覽器中操作所有功能。

## 📱 功能清單

- **首次使用歡迎引導（Onboarding）**：
  - 體重輸入（大步進器）
  - 生活狀態三選一（日常健康、體重管理、規律運動）
  - 獨立公式計算建議值（四捨五入至整數百毫升，附醫學免責說明）
  - 自訂每日目標（＋/－ 100 mL）
  - 每日兩次提醒時間設定（預設 11:30、17:00）
- **首頁核心互動**：
  - 圓潤水杯動態波浪水位（依完成百分比平滑上升）
  - 智慧叮嚀卡片（依時段與喝水進度自動切換溫柔問候）
  - 三大快速喝水按鈕（＋200、＋300、＋500 mL）
  - 點擊互動小助理（溫馨問候吐司語句）
  - Web Audio 溫和水滴聲（Plop）與觸覺微震動回饋
  - **復原上一筆記錄（Undo）**：避免誤按
  - 自訂喝水量輸入彈窗
  - 100% 達標慶祝彈窗
  - 近 7 天水滴記錄（藍色實心水滴代表達標）
  - 30 則無誇大宣稱的健康喝水生活小知識（隨機輪播與換一則）
- **設定頁面**：
  - 調整體重、生活狀態與每日目標
  - 修改兩次提醒時間
  - 開啟／關閉溫柔提醒與推播測試
  - 音效與震動開關
  - 隨時重新進行歡迎設定引導
